# Modes (live co-writing with the author)

Three sessions, reached by what the author says. They come from Matt Pocock's writing-fragments, writing-shape, and writing-beats skills (MIT; see `LICENSE` in this folder).

- "mine fragments", "let's explore", "I don't know what this is yet" → `explore.md`
- "shape this pile", "turn this into an article" → `shape.md`
- "beats", "walk me through it beat by beat" → `beats.md`

Explore widens; shape and beats commit. Do not mix them in one session.
